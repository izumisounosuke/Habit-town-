# 習慣の町

毎日の記録に応じて町が育つ習慣トラッカー。PWAとして動作し、オフラインでも起動します。

## ファイル構成

```
index.html            アプリ本体（HTML/CSS/JSすべて）
manifest.webmanifest  ホーム画面追加・スタンドアロン起動の設定
sw.js                 オフライン用サービスワーカー
icons/                アイコン一式
```

## 公開手順（GitHub Pages）

1. GitHubで公開リポジトリを作る（例：`habit-town`）
2. この4点（`index.html` / `manifest.webmanifest` / `sw.js` / `icons` フォルダ）をそのままアップロード
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/habit-town/` が有効になる
5. スマホでそのURLを開き、Safariなら共有ボタン →「ホーム画面に追加」、Chromeならメニュー →「ホーム画面に追加」

以降はアイコンから全画面で起動し、通信がなくても開けます。

## ローカルで確認する場合

`file://` で開くと保存が効かない場合があるため、簡易サーバーを使ってください。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## データについて

- 記録はブラウザの localStorage に保存されます（端末内・自動送信なし）
- 3項目を毎日記録しても1年で数十KB程度。10年運用しても容量上限には届きません
- 「バックアップを保存」でJSONファイルを書き出せます。機種変更・ブラウザデータ削除に備え、月1回程度の保存を推奨
- 復元は「バックアップから復元」でJSONを選択（現在の記録は置き換えられます）

## 更新のしかた

`index.html` を書き換えたら、`sw.js` の `CACHE` の値（`habit-town-v1`）を `v2`、`v3` と変更してからアップロードしてください。値が変わらないと古いキャッシュが使われ続けます。

## ポイントと町

| 行動 | pt |
|---|---|
| 最低ライン達成 | 1 |
| 目標達成 | 3 |
| 目標を超えた分（「＋」／1日3回まで） | 各2 |
| その日の全項目が最低ライン以上 | 2 |

主要な建物は累計4,500ptまでに20棟。その間と以降は、110ptごとに家や木が増えていきます。

## できること

- **タスクの3段階記録** — 未実施 / 最低ライン / 目標達成をタップで切り替え。目標超過は「＋」で1日3回まで
- **小項目** — 1つのタスクの中にチェックリスト（筋トレの種目など）。達成率とptには影響しない進捗の目印
- **タイマー** — タスクごとに「開始」で計測。アプリを閉じても計測は続き、目標時間に達すると通知・バイブ・音で知らせます
- **時間の手入力** — 「＋5分」「＋15分」「＋30分」「分を入力」
- **月の大目標** — 1か月に3つまで。達成で100pt
- **達成率** — 当日 / 週 / 月 / 年で切り替え、◀▶で過去もさかのぼれます
- **学習時間の集計** — 期間合計、タスク別、目標時間に対する比率、直近14日の棒グラフ
- **記録ビュー** — 4週間ヒートマップ、1年グリッド、通算統計
- **町** — ptに応じて建物が増える。20棟の主要建築＋家並み

## 達成率の見かた

- **総合の達成率** = 最低ライン以上を達成した項目数 ÷ 対象項目数
- **目標達成率** = 目標まで到達した項目数 ÷ 対象項目数
- **完全達成率** = 全項目を最低ライン以上で終えた日 ÷ 対象日数
- 習慣ごとの行は、上の濃いバーが最低ライン以上、下の緑のバーが目標到達

分母の決め方には次のルールがあります。

- 対象日数は「記録開始日」以降、かつ今日までに限定（未来日と、使い始める前の日は分母に入りません）
- 各日の対象項目数は、その日に登録されていた習慣の数を記録時点で保存しているため、後から習慣を増減しても過去の達成率は変わりません
- 「週◯回」設定の習慣は、日数を7で割った回数を分母にします（月なら約4.3週分）

## データ保持の仕組み

- 保存のたびに直前の内容を予備キーに退避します。本体が壊れて読めない場合は自動的に予備から復元し、その旨を画面に表示します
- 旧バージョン（v1/v2）のデータは初回起動時に自動で新形式へ変換されます
- 習慣は削除ではなく「終了にする」でアーカイブされ、過去の記録・ptは保持されます
- 記録が2週間分を超えた時点と、前回バックアップから30日経過した時点で、バックアップの案内が出ます
